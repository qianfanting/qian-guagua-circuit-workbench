# 钱呱呱电路工作台

一个在浏览器中使用的电气电路拖拽工作台。将元件放到画布上、连接导线，并通过演示模式观察基础开关和负载的状态。

专门为使用 macOS、无法运行学校指定软件的大学生制作。

## 在线使用

[打开电路工作台](https://qianfanting.github.io/qian-guagua-circuit-workbench/)

## 功能

- 拖放电源、开关、保护器件、负载、仪表等元件，移动、重命名和旋转元件。
- 点击或拖动元件端点接线，设置折点和导线颜色。
- 使用简单示例与演示模式，查看基础开关、负载及简化变压器的联动效果。
- 撤回操作、将工程保存为 JSON，以及重新导入工程。

## 本地运行

下载仓库后直接用浏览器打开 `index.html`。页面是单个 HTML 文件，不需要安装依赖或启动服务器。

## 说明

演示模式用于绘图和逻辑展示，不能代替专业电气设计、仿真或安全校核。工程文件由浏览器下载到本机；请自行保管保存的 JSON 文件。
